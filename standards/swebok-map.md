# SWEBOK v4.0 (IEEE Computer Society) — Coverage Map
> SWEBOK Guide V4.0 (ed. Hironori Washizaki, IEEE CS, 2024; minor-revision release **v4.0a**, 25 Sep 2025) organizes software engineering into **18 Knowledge Areas (KAs)** plus an appendix on standards; three KAs are new in v4.0 (Software Architecture, Software Engineering Operations, Software Security). Each KA below lists intended topic ids (Strata track = first path segment), verified against the IEEE CS V4.0 topics table of contents.

## Software Requirements
- `engineering-process/requirements-elicitation` — requirements sources, elicitation techniques
- `engineering-process/requirements-analysis` — basic/formal analysis, QoS economics, conflict resolution
- `engineering-process/requirements-specification` — natural language, acceptance criteria, model-based specs
- `engineering-process/requirements-validation` — reviews, simulation, prototyping
- `engineering-process/requirements-management` — scrubbing, change control, tracing, prioritization
- `engineering-process/requirements-tools` — management, modeling, test-case generation tools

## Software Architecture
- `architecture-design/architecture-fundamentals` — senses of architecture, stakeholders, concerns
- `architecture-design/architecture-description` — views/viewpoints, patterns, styles, ADLs, frameworks
- `architecture-design/architecture-process` — architecting in context, analysis, synthesis, tactics
- `architecture-design/architecture-evaluation` — goodness, reasoning, reviews, metrics

## Software Design
- `architecture-design/design-fundamentals` — design thinking, key issues, design principles
- `architecture-design/design-processes` — high-level and detailed design
- `architecture-design/design-qualities` — concurrency, persistence, distribution, fault tolerance, variability
- `architecture-design/design-description` — model-based, structural/behavioral descriptions, rationale
- `architecture-design/design-strategies-methods` — structured, OO, component-based, event-driven, user-centered
- `architecture-design/design-evaluation` — reviews, quality attributes, measures, V&V of designs

## Software Construction
- `programming/construction-fundamentals` — minimizing complexity, reuse, standards, verification
- `programming/construction-management` — construction planning, measurement, dependency management
- `programming/construction-practices` — coding, testing, integration, cross-platform migration
- `programming/construction-technologies` — APIs, generics, DBC, exception handling, concurrency, middleware
- `programming/construction-tools` — IDEs, low-code platforms, unit testing, profiling tools

## Software Testing
- `quality-testing/testing-fundamentals` — faults vs failures, testability, oracle problem, adequacy criteria
- `quality-testing/test-levels` — unit, integration, system, acceptance; regression, non-functional testing
- `quality-testing/test-techniques` — equivalence partitioning, boundary analysis, decision tables, mutation
- `quality-testing/test-measures` — fault density, reliability growth models, mutation score
- `quality-testing/test-process` — planning, design, execution, incident reporting, test management
- `quality-testing/testing-tools` — tool support, selection, automation categories

## Software Engineering Operations
- `operations/operations-fundamentals` — installation, scripting/automation, troubleshooting, load balancing
- `operations/operations-planning` — operations plan, capacity, availability, backup/disaster recovery
- `operations/operations-delivery` — deployment/release engineering, rollback, change and problem management
- `operations/operations-control` — incident management, monitoring, support, service reporting
- `operations/operations-practices` — incident prevention, operational risk, automation, small orgs
- `operations/operations-tools` — containers/virtualization, deployment, telemetry/monitoring tools

## Software Maintenance
- `operations/maintenance-fundamentals` — definitions, categories of maintenance, evolution of software
- `operations/maintenance-key-issues` — impact analysis, maintainability, technical debt, cost estimation
- `operations/maintenance-processes` — maintenance activities, planning, configuration management
- `operations/maintenance-techniques` — program comprehension, reengineering, reverse engineering, CI/CD
- `operations/maintenance-tools` — tool support for maintenance tasks

## Software Configuration Management
- `engineering-process/scm-process-management` — SCM planning, organizational context, monitoring
- `engineering-process/configuration-identification` — configuration items, baselines, libraries
- `engineering-process/change-control` — change requests, control boards, deviations and waivers
- `engineering-process/status-accounting` — status information and reporting
- `engineering-process/configuration-auditing` — functional and physical configuration audits
- `engineering-process/release-management` — software building, release management and delivery

## Software Engineering Management
- `engineering-process/project-initiation-scope` — requirements negotiation, feasibility analysis
- `engineering-process/project-planning` — effort/schedule/cost estimation, risk, resource allocation
- `engineering-process/project-execution` — plan implementation, monitoring, control, reporting
- `engineering-process/project-review-evaluation` — requirements satisfaction, performance review
- `engineering-process/project-closure` — closure determination and activities
- `engineering-process/engineering-measurement` — measurement process planning, performance, evaluation

## Software Engineering Process
- `engineering-process/process-fundamentals` — process definition and key concepts
- `engineering-process/life-cycle-models` — life cycles, process models, adaptation (agile/waterfall)
- `engineering-process/process-assessment-improvement` — GQM, framework-based methods, agile process improvement

## Software Engineering Models and Methods
- `architecture-design/modeling-fundamentals` — modeling principles, syntax/semantics, invariants
- `architecture-design/model-types` — structural and behavioral modeling
- `architecture-design/model-analysis` — completeness, consistency, correctness, traceability
- `architecture-design/engineering-methods` — heuristic, formal, prototyping, agile methods

## Software Quality
- `quality-testing/quality-fundamentals` — culture, value/costs of quality, dependability, integrity levels
- `quality-testing/quality-management-process` — quality improvement, planning, measurement, corrective action
- `quality-testing/quality-assurance-process` — process/product assurance, V&V, static/dynamic analysis
- `quality-testing/quality-tools` — tool support for quality management and assurance

## Software Security
- `security/security-fundamentals` — software security, information security, cybersecurity
- `security/security-management-organization` — capability maturity, ISMS, agile security practices
- `security/security-engineering-processes` — secure SDLC, Common Criteria evaluation
- `security/security-engineering-systems` — security requirements, design, patterns, construction, testing
- `security/security-tools` — vulnerability checking, penetration testing tools
- `security/domain-specific-security` — container/cloud, IoT, machine learning-based security

## Software Engineering Professional Practice
- `engineering-process/professionalism` — accreditation, certification, licensing, ethics codes
- `engineering-process/legal-issues` — patents, copyrights, trade secrets, liability, data privacy
- `engineering-process/group-dynamics-psychology` — teamwork, cognition, stakeholders, uncertainty, DEI
- `engineering-process/communication-skills` — reading, writing, team communication, presentations

## Software Engineering Economics
- `engineering-process/economics-fundamentals` — cash flow, time value of money, business models
- `engineering-process/decision-making-process` — engineering alternatives evaluation and selection
- `engineering-process/for-profit-decision-making` — rate of return, economic life, replacement decisions
- `engineering-process/nonprofit-decision-making` — benefit-cost and cost-effectiveness analysis
- `engineering-process/estimation` — expert judgment, analogy, decomposition, parametric, multiple estimates
- `engineering-process/intangible-assets` — identification, characterization, linkage to business model

## Computing Foundations
- `cs-foundations/computing-system-basics` — basic concepts of a system or solution
- `cs-foundations/computer-architecture` — von Neumann/Harvard, ISA, Flynn taxonomy, organization
- `cs-foundations/data-structures-algorithms` — data structures, algorithm complexity, sorting/searching/hashing
- `cs-foundations/programming-languages` — language types, syntax/semantics, OOP, concurrency, debugging
- `cs-foundations/operating-systems` — processor, memory, device, information, network management
- `cs-foundations/database-management` — schema, data models, SQL, normalization, backup/recovery
- `cs-foundations/computer-networks` — network types, OSI, protocol suites, wireless, security
- `cs-foundations/ai-ml-foundations` — reasoning, learning, models, NLP, AI and software engineering

## Mathematical Foundations
- `cs-foundations/basic-logic` — propositional and predicate logic
- `cs-foundations/proof-techniques` — direct proof, contradiction, induction
- `cs-foundations/sets-relations-functions` — set operations, relations, functions
- `cs-foundations/graphs-trees` — graphs, trees
- `cs-foundations/finite-state-machines` — FSM models and applications
- `cs-foundations/number-theory` — types of numbers, divisibility, primes, GCD
- `cs-foundations/basics-of-counting` — combinatorial counting fundamentals

## Engineering Foundations
- `hardware/engineering-process-fundamentals` — the engineering process
- `hardware/engineering-design` — design as problem solving, engineering design education
- `cs-foundations/abstraction-encapsulation` — levels of abstraction, encapsulation, hierarchy
- `cs-foundations/empirical-methods` — designed experiments, observational and retrospective studies
- `cs-foundations/statistical-analysis` — sampling, correlation and regression
- `cs-foundations/modeling-simulation-prototyping` — modeling, simulation, prototyping
- `cs-foundations/root-cause-analysis` — RCA techniques, root cause-based improvement
