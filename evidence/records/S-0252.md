NIST's SSDF is a core set of fundamental, outcome-based secure software
development practices, derived from established practice documents from BSA,
OWASP, and SAFECode, designed to be integrated with each SDLC implementation.
Practices are organized into four groups — Prepare the Organization (PO),
Protect the Software (PS), Produce Well-Secured Software (PW), Respond to
Vulnerabilities (RV) — each defined by practices, tasks, notional
implementation examples, and references. The intention is explicitly NOT a
checklist: risk, cost, feasibility, applicability, and automatability guide
which practices to adopt. Version 1.1 adds PO.5 (secure environments), PO.1.2
(documented security requirements), PS.3.2 (provenance data), PW.1.2
(requirements/risk/design-decision tracking), and an Appendix A mapping
Executive Order 14028 §4e clauses to practices. Verified via csrc.nist.gov
project page.
