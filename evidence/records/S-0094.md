Codified consensus (Internet Standard) specifying HTTP/2: an optimized
expression of HTTP semantics with multiple concurrent exchanges on a
single connection via streams (Section 5), binary message framing, and
field (header) compression (HPACK); TCP head-of-line blocking is not
addressed by HTTP/2. Authoritative source for HTTP/2 claims in
`systems-software/http-basics`.
