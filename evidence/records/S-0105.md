Official Rust book: ownership rules (each value has one owner; only one owner
at a time; the value is dropped when the owner goes out of scope), moves vs
copies, references and borrowing (at any time either one mutable reference or
any number of immutable references; references must always be valid), the
borrow checker as a compile-time discipline, and unsafe code as a locally
scoped opt-out of those guarantees. Basis for the T3 ownership claims of the
memory-model-and-pointers topic.
