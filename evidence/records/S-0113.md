Canonical practitioner text on Linux kernel internals: the task_struct
process descriptor (the Linux PCB), process creation via fork()/clone(),
threads implemented as tasks that share the address space (CLONE_VM), and
the mechanics of context switching. Establishes that Linux's
process/thread distinction is a sharing decision, not two abstractions.
