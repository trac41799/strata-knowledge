First replication algorithm to make Byzantine fault tolerance practical: it
works in asynchronous systems like the Internet and tolerates up to f
Byzantine-faulty replicas with n = 3f + 1 replicas via pre-prepare, prepare,
and commit phases with message authentication. Includes a correctness
argument plus an experimental evaluation (quasi-experiment) showing
near-production performance.
