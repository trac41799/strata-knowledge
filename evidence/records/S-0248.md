OWASP's collection of concise application-security guidance (continuously updated;
index verified 2026-08-17). Pages relied on by the security packs: SQL Injection
Prevention (primary defense: prepared statements/parameterized queries; stored
procedures and allow-list validation secondary; escaping strongly discouraged);
Cross Site Scripting Prevention (context-aware output encoding by rendering
context; sole reliance on CSP is an anti-pattern; Trusted Types for DOM sinks);
DOM based XSS Prevention (reflected/stored are server-side injection, DOM-based is
client-side injection); Cross-Site Request Forgery Prevention (server-generated
synchronizer token pattern; SameSite/Secure/HttpOnly cookie attributes);
Session Management (session IDs need >=64 bits of entropy; HttpOnly mandatory
against XSS theft; SameSite Strict or Lax, never None without Secure; regenerate
IDs on privilege change; invalidate server-side on logout); Password Storage
(Argon2id recommended — 2015 Password Hashing Competition winner; scrypt when
Argon2 unavailable; bcrypt legacy only with work factor >=10); JSON Web Token
(alg:"none" acceptance and key/algorithm confusion as forgery vectors; enforce
algorithm allow-lists at validation); OAuth2 (PKCE for public clients using the
authorization code grant); Content Security Policy (restricts inline scripts,
remote scripts, and eval as XSS defense in depth); HTTP Strict Transport Security
(max-age, includeSubDomains, preload list); Multifactor Authentication;
Authorization (RBAC/ABAC models; deny by default).
