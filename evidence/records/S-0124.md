Codified U.S. government guidance (NIST) for container security, organizing
risks and countermeasures across the container lifecycle: image, registry,
orchestrator, container runtime, and host OS. Establishes that containers
share the host kernel, making the kernel a common attack surface; that
vulnerabilities in runtime software can be used to escape a container and
attack other resources; that insecure runtime configurations (e.g., allowing
containers to mount sensitive host directories) enlarge the escape surface;
and that registries are effectively file storage for images wrapped in APIs.
Recommended countermeasures include least-privilege runtime configuration,
minimized capabilities, patching, and secure image/registry practices.
