RAG combines parametric memory (the weights of a pretrained generator, here
BART-large) with non-parametric memory (a dense index of Wikipedia passages,
retrieved with a DPR bi-encoder; maximum inner product search via FAISS).
Retrieved top-k passages condition generation (RAG-Sequence / RAG-Token
variants). Achieves state-of-the-art exact-match on open-domain QA datasets
(Natural Questions, WebQuestions, CuratedTrec), outperforming closed-book
generative models (T5-11B) and extractive systems (REALM, DPR). Because the
external index is decoupled from the parameters, it can be updated without
retraining the generator. Verified against arXiv:2005.11401 abstract and
secondary analyses.
