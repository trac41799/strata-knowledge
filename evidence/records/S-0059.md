Proves Rice's theorem: for any class of recursively enumerable sets that is
neither empty nor contains all r.e. sets, the index set of the class is not
recursive — every non-trivial property of the partial function computed by a
program (a semantic, input/output-behavior property) is undecidable. Formal
basis for the Rice's-theorem and program-analysis claims of this topic.
