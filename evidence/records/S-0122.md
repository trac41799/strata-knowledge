Open Container Initiative specifications defining the de facto container
format and runtime contract. The image-spec defines an image as an ordered
collection of root filesystem changes (layers) plus the execution parameters,
content-addressed via content descriptors arranged in a Merkle DAG (which is
how identical layers are shared across images), and how an image is unpacked
into an OCI runtime bundle. The runtime-spec defines the bundle layout, the
configuration schema (process, root filesystem, mounts, and Linux-specific
namespaces, cgroup path, and resource limits), and the runtime lifecycle.
Verified at github.com/opencontainers (runtime-spec releases; image-spec
README; image-spec v1.1.0-rc3 PDF: "An OCI Image is an ordered collection of
root filesystem changes and the corresponding execution parameters").
