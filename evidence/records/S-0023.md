Defines HTTP message semantics shared across protocol versions: request
methods, status codes (including 304 Not Modified), header fields (ETag,
Last-Modified, Vary, Date), and the conditional-request machinery
(If-None-Match, If-Modified-Since) with weak/strong validator comparison.
Caches depend on these semantics for revalidation (see S-0009).
