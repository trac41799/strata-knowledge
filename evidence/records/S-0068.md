Ratified open-standard ISA specification. Defines the RV32I base set of 40
unique instructions, the six core instruction formats (R/I/S/B/U/J), 32
general-purpose registers with x0 hardwired to zero, little-endian base,
load-store memory access, unaligned-access handling as an implementation
choice, and the standard extensions (M, A, F, D, Q, C). The reference for
compiler writers and implementers; frozen as version 20191213.
