Introduces SWE-bench, a task-level evaluation for language models and agents:
2,294 task instances drawn from real GitHub issues and their resolving pull
requests across 12 popular Python repositories. A model receives the codebase
and an issue description and must produce an edit such that the held-out tests
pass — full issue resolution, not single-edit scoring. At release, models
resolved only a small fraction of instances (e.g., Claude 2: 1.96%); the
authors conclude existing static benchmarks had become saturated and that
models handle only the simplest tasks, motivating execution-based,
task-level evaluation. Verified against the paper (arXiv:2310.06770) and
project page.
