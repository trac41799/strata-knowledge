Official Redis documentation for memory management in cache use: the
maxmemory directive caps Redis memory; maxmemory-policy selects the eviction
behavior — noeviction (the default: write commands return errors when the
limit is reached), allkeys-lru/lfu/random (any key eligible), and
volatile-lru/lfu/ttl (only keys with a TTL/expire set are eligible; volatile
policies behave like noeviction if no keys have an associated expiration).
Redis also supports per-key TTL via EXPIRE; expired keys are deleted and
subsequently treated as missing.
