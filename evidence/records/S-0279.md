Anthropic's practitioner guidance (Dec 2024) on building agentic systems:
agents are "typically just LLMs using tools based on environmental feedback in
a loop"; workflows orchestrate LLMs through predefined code paths, while agents
let the LLM dynamically direct its own process and tool usage. Standard
patterns: prompt chaining, routing, parallelization (sectioning, voting),
orchestrator-workers (a central LLM dynamically decomposes tasks, delegates to
worker LLMs, synthesizes results) and evaluator-optimizer loops. Guidance:
agents are for open-ended problems, need some level of trust in the model's
decision-making, gain ground truth from the environment at each step, may pause
for human feedback at checkpoints, and need stopping conditions; toolsets and
their documentation are the crucial reliability lever; start with direct LLM
API calls and use frameworks (Claude Agent SDK, Strands Agents SDK by AWS,
Rivet, Vellum) only when they reduce complexity; mentions the Model Context
Protocol as a tool-integration approach. Verified against the live document
(accessed 2026-08).
