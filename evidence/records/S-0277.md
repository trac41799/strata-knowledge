Introduces ReAct, an agent loop that interleaves reasoning traces (thoughts)
with task-specific actions executed against an environment, feeding the
resulting observations back into the model. On knowledge tasks (HotpotQA,
FEVER), ReAct overcomes hallucination and error propagation prevalent in
chain-of-thought by querying a Wikipedia API, and produces more interpretable
trajectories. On ALFWorld, 1-2-shot ReAct reaches 71% success vs 45% for the
action-only baseline and 37% for imitation learning trained on ~1e5 expert
trajectories; on WebShop, one-shot ReAct gains ~10 absolute points over prior
imitation/reinforcement learning methods. Verified against the ICLR paper
(arXiv:2210.03629) and project page.
