Official documentation of the framework that popularized snapshot testing.
Describes snapshot tests as comparing a serialized value (e.g., a rendered
component tree) against a committed artifact: the test fails on mismatch and
is updated via a flag (`jest -u` / `--updateSnapshot`). Documents the
pitfalls of the practice: snapshots must be reviewed like code in code
review; bulk regeneration of snapshots can mask unintended changes; and
descriptive test/snapshot names are required so reviewers can judge whether
a snapshot change is intended. Canonical practitioner reference for
snapshot-testing benefits (cheap regression canaries for UI output) and
limits (equality against an artifact, not behavioral assertion). Web-verified
at jestjs.io/docs/snapshot-testing (accessed 2026-08-18).
