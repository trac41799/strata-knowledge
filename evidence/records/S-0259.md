Open-access paper (verified full text) reviewing binary-classifier evaluation:
confusion-matrix measures (precision = PPV = TP/(TP+FP); recall = sensitivity
= TPR = TP/(TP+FN); specificity; accuracy), threshold-free plots (ROC: TPR vs
FPR over all thresholds, AUC 0.5 = random, 1.0 = perfect; PRC: precision vs
recall, baseline y = P/(P+N) shifting with class distribution), and their
behavior under class imbalance. Simulation (1000 iterations) and literature
analysis (60.3% of SVM-based imbalanced studies use ROC, only 6.0% use PRC)
show ROC plots can be visually deceptive on imbalanced data while PRC plots
expose poor precision among positive predictions.
