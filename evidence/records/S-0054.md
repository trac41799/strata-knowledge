Defines universal families of hash functions: a class H with the property that
for any two distinct keys, at most a bounded fraction of functions in H map
them to the same slot. Proves that picking a hash function randomly from a
universal class gives input-independent expected linear time for storage and
retrieval — the formal basis of the expected O(1) guarantees of hash tables.
Primary source for the hashing claims of `cs-foundations/data-structures`.
