The international SQL standard, 3rd edition (SQL-92). Codifies the
transaction model of relational databases: SET TRANSACTION ISOLATION
LEVEL with four levels (READ UNCOMMITTED, READ COMMITTED, REPEATABLE
READ, SERIALIZABLE) defined by the prohibited phenomena P1 (dirty
read), P2 (non-repeatable read), and P3 (phantom). Superseded by later
ISO/IEC 9075 editions (1999 onward), which keep the same four-level
model. The lost-update (dirty-write) anomaly is not part of this
standard's taxonomy.
