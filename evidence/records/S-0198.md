The original LSM-tree paper: a disk-based structure for files with
high insert (and delete) rates. Index changes are deferred and
batched: writes go to a memory-resident component and cascade through
one or more disk components via merge-sort-style merges (compaction),
converting random writes into sequential batch writes, while all index
values remain continuously accessible to retrievals. Includes a cost
analysis of insert/retrieve/delete tradeoffs against B-trees —
establishing the read-cost/write-cost tradeoff (read and space
amplification in exchange for lower write cost) later called write
amplification in the storage literature.
