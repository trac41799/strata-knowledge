Codified consensus (Internet Standard) specifying the HTTP/1.1 message
syntax and connection management: persistent connections as the default
(Section 9.3), the "close"/"keep-alive" connection options, pipelining
(Section 9.3.2), the mandatory Host header (Section 3.2), message framing
(Content-Length, chunked transfer), and HTTP/1.0 compatibility
(Appendix C.2.2). Authoritative source for HTTP/1.1 claims in
`systems-software/http-basics`.
