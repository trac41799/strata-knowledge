Widely adopted open-source specification for telemetry: organizes observability
into signals — traces, metrics, logs, plus baggage — built on context
propagation as the shared correlation mechanism; defines APIs, SDKs, the
OpenTelemetry Protocol (OTLP), and the Collector (which can perform
aggregation and sampling). The logs data model defines structured log
records (timestamp, severity, body, attributes, trace/span correlation
fields). The metrics documentation defines cardinality — the number of
unique attribute combinations per metric stream — and the SDK enforces a
per-stream cardinality limit (default 2,000 unique attribute combinations,
with overflow aggregated under `otel.metric.overflow=true`) to bound memory
cost. The traces signal supports sampling to control volume and cost.
