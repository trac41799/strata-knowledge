Report on Google's globally distributed SQL database, deployed across
hundreds of datacenters on multiple continents. Data is sharded into
Paxos-replicated groups; multi-shard transactions use two-phase commit (2PC)
executed over those Paxos groups, which "mitigates the availability problems"
of classic 2PC because each participating group tolerates minority failures.
TrueTime — a clock API with bounded uncertainty built from GPS receivers and
atomic clocks — allows external-consistency timestamps, a property stronger
than linearizability, which Spanner was the first system to provide at global
scale. An archetypal NewSQL system: SQL interface, ACID transactions, and
horizontal scalability. Web-verified: usenix.org conference record and
Google Cloud Spanner documentation ("TrueTime and external consistency").
