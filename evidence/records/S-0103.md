Codified consensus definition of the C language. Relevant clauses for this
topic: 3.4.3 (undefined behavior definition), 5.1.2.4 (memory model and data
races: conflicts, happens-before, races are UB), 6.2.4 (storage durations and
object lifetime; pointer values become indeterminate at lifetime end), 6.3.2.1
(array-to-pointer conversion), 6.3.2.3 (pointer conversions: null pointer,
pointer/integer casts), 6.7.3.1 (restrict), 7.17 (atomics), 7.22.3.3 (free of
null pointer is a no-op), Annex J.2 (enumerated undefined behaviors).
