Reports paging experiments in which shrinking the memory store made programs
run faster and gives a formal treatment for the FIFO replacement algorithm:
increasing the number of page frames can increase the page-fault count.
This constructed counterexample is Bélády's anomaly; it shows "more memory"
does not guarantee fewer faults for FIFO-style replacement.
