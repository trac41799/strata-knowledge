Standard textbook (widely used in graduate architecture courses). Defines
coherence via the single-writer-multiple-reader (SWMR) invariant; covers the
MSI/MESI/MOESI state families, snooping vs directory protocols, invalidate vs
update, write/store buffers and their ordering effects, the SC / TSO (x86) /
relaxed (Power, ARM) consistency spectrum, and why directory protocols scale
where snooping does not.
