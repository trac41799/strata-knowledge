Defines two Cache-Control extensions: stale-while-revalidate, which lets a
cache serve a stale response while revalidating in the background, and
stale-if-error, which allows serving stale content when the origin returns
an error. Both are incorporated into RFC 9111 (S-0009) as normative
directives.
