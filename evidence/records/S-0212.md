NIST analysis of naturally occurring failures in medical device software and
NASA distributed systems (with companion data for browser/server software and
network security systems), showing that failures are typically triggered by
interactions of few variables: across domains, one- and two-variable
interactions accounted for 65-97% of failures (medical devices 97%, browser
76%, server 70%, NASA GSFC 93%, network security 65%), three-way coverage
reached 89-99%, and four-way 96-100% (100% for medical devices and NASA).
No studied domain required more than six interacting variables. Basis for the
pairwise/combinatorial testing practice ("the Interaction Rule") and for
pseudo-exhaustive n-way testing as a stand-in for exhaustive testing.
