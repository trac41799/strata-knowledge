The original B-tree paper. Defines the balanced multiway search tree (order-m
B-trees: all leaves at the same depth, nodes holding up to 2m keys), gives the
formal complexity analysis — tree height grows logarithmically in the number of
keys n for fixed node capacity, so every search, insertion, and deletion
touches O(log n) nodes — and presents the insertion and deletion algorithms
with node splitting and merging that maintain balance as the tree grows. This
is the proof basis for the B-tree height and page-access complexity claims.
