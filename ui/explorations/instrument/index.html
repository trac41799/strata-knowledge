Claim: Cache-Control max-age makes a response reusable for that many seconds from origin

Resolution: systems-software/http-caching · 21 claims checked · 2 matched

MATCHED CLAIMS (concept.md)
  • max-age=N declares the response stale once its age exceeds N seconds counted from the time the response was generated. T2S-0009
  • A stored response may satisfy a request only while it is fresh: its age must not exceed its freshness lifetime. T2S-0009
GAPS FOUND
  • correct for shared caches when freshness from origin is unconstrained
  • age counters (Age header, resident time) missing — freshness is measured from generation, not receipt
  • stale-while-revalidate / stale-if-error reuse windows missing
CORRECTED MENTAL MODEL

max-age declares how long a response may be reused from the moment it was generated; a cache computes current age from Date/Age and serves only while age ≤ lifetime, otherwise revalidates (If-None-Match preferred) or applies stale-reuse directives.
