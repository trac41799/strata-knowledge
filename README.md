# Strata — Software Engineering Knowledge & Agent Context Layer

Strata is a standards-grounded, evidence-tiered knowledge base covering software
development from system design (high) down to hardware (low), wrapped in an agent
harness so any coding agent can validate your understanding, teach you at your
level, and log your learning journey.

- Start here: `OVERVIEW.md`
- Design: `docs/spec.md` (specification) · `docs/plan.md` (implementation plan)
- Agents: `AGENTS.md` governs how any agent uses this repo — read it first if you are one.
- Status: Phase 0 (foundations/conventions) — knowledge content starts in Phase 2.
